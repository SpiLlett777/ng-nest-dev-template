# Development seed

Команда `yarn db:main:seed` полностью очищает локальную main-базу и создаёт
детерминированный набор данных для ручной проверки приложения.

Перед запуском должны быть доступны PostgreSQL и MinIO:

```bash
yarn start:api-deps:docker
yarn db:main:deploy
yarn db:main:seed
```

Тестовые аккаунты используют пароль `Admin123`:

- `admin@example.com` — суперадминистратор (`SUPER_ADMIN`) и основной владелец
  контента;
- `user@example.com` — обычный пользователь;
- остальные логины перечислены в `users.ts`.

Эти данные предназначены только для локальной разработки. Не запускайте seed и
не используйте тестовый пароль в production. При `NODE_ENV=production` seed
завершится ошибкой до очистки базы.
